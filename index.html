About

我是陈科宏，浙江台州人，沈阳理工大学计算机专业大一。

2008 年 7 月出生，台州靠海，我在这里长大。2026 年 9 月来沈阳上学，从东南沿海到东北，跨度挺大。基础课排得挺满，我想先把课上明白，再谈以后做什么。

Python 用得更顺手一些，主要拿来写脚本、处理数据、折腾 AI 工具。学得不算快，但每个新东西我都会自己动手写一遍——包括你正在看的这个主页。

在学什么

Learning

只写现在真的在碰的东西。纯萌新，下面的百分比只是给自己看的，不代表水平，也不跟别人比。

01 刚上手

Python

30%

用得最多的一门，但还停在写小脚本、改别人代码的阶段。读文件、调 API 能跑通，数据处理刚入门。

02 入门中

C 语言

18%

第一门真正意义上的语言。数组、字符串、函数刚过完，能照着例子写出能跑的小程序，调试基本靠 printf。

03 刷题中

数据结构与算法

8%

跟着课和题单走，链表、栈、排序刚写了几遍。复杂度的直觉还没有，卡住是常态，每道题记一句当时卡在哪。

04 照着写

HTML / CSS / JS

25%

你正在看的这个页面就是它。手写、没有框架，但大多是照着文档一点点拼出来的，改几行 CSS 就能换个样子。

05 刚入门

Git / 命令行

12%

add、commit、push 刚用熟，分支还经常搞混，rebase 完全没碰过。命令行比鼠标点来点去快一点。

06 在用

AI 工具链

28%

用大模型当学习和编码助手：解释报错、生成练习、总结课件。但它说得对的地方我也常常没看懂，得自己再核对一遍。

纯萌新一个：目前能看懂、能改、能跑通，离自己独立写还差得远。上面的百分比是给自己看的，过几个月再看可能会笑。

我的循环
  1. 读文档
  2. 自己写一遍
  3. 让它报错
  4. 记一句
  5. 过几天再写
