About

我是 Elaine，一个住在上海的前端工程师。

我写 JavaScript，也写字。喜欢把界面上的每一条线、每一个间距都调到舒服为止——这大概是我最早理解的「前端」。

2015 年注册 GitHub 之后，做过 React Native 的豆瓣电影、用 Node + MongoDB 搭过博客后端、写过微信小程序，也翻译过 Vue 2.0 的更新日志。现在更多时间花在工程化、组件和体验细节上。

这个网站是我自己的涂鸦墙：作品、笔记，和一些不想丢掉的想法。它没有用框架，只有一个 HTML、一份 CSS 和一点点 JavaScript。
